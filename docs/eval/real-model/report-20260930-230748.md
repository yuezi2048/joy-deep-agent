# 幂等：三句话解释

幂等是指同一操作执行一次与执行多次，对系统状态产生的影响相同。它常用于 HTTP 接口重试、支付扣款、消息重复投递等场景。与非幂等操作不同，幂等操作重复执行不会造成额外副作用，因此可以安全地重试。
